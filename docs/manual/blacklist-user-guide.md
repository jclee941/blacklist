# Blacklist 사용자 가이드

**버전:** 저장소 루트 [`VERSION`](../../VERSION) 기준

이 문서는 Blacklist 대시보드를 사용해 블랙리스트를 조회하고 활용하는 사용자를 위한 안내서입니다. 수집 설정·연동·운영 작업은 [관리자 가이드](blacklist-admin-guide.md)를 참조하십시오.

## 1. 접속, 로그인, 로그아웃

브라우저에서 배포된 주소(예: `https://blacklist.example.local`)에 접속하면 로그인 화면으로 이동합니다.

![로그인](screenshots/login.png)

- 관리자가 발급한 사용자 이름과 비밀번호를 입력하고 **로그인**을 선택합니다.
- 로그인에 성공하면 대시보드로 이동합니다. 발급된 자격증명이 없거나 인증이 거부되면 관리자에게 문의하십시오.
- 데스크톱에서는 상단 우측의 로그아웃 아이콘을 선택합니다. 모바일에서는 상단 메뉴를 열고 **로그아웃**을 선택합니다.
- 로그아웃하면 현재 브라우저의 인증 정보가 삭제되고 로그인 화면으로 이동합니다.

## 2. 대시보드

![대시보드](screenshots/dashboard.png)

로그인 후 첫 화면입니다. 상단 메뉴로 모든 기능 페이지에 이동할 수 있으며, 우측 배지로 시스템 상태(`정상`)를 확인할 수 있습니다.

### 통계 카드

| 카드         | 의미                             |
| ------------ | -------------------------------- |
| 전체 IP 주소 | 현재 수록된 블랙리스트 IP 총수   |
| 차단된 IP    | 차단 대상으로 활성화된 IP 수     |
| 24시간 신규  | 최근 24시간 내 새로 수록된 IP 수 |
| 화이트리스트 | 차단 예외로 등록된 IP 수         |

**빠른 작업** 카드로 자주 쓰는 기능(IP 관리, 데이터 수집, 일별 통계, FortiGate 연동, 데이터베이스)에 바로 이동할 수 있습니다. `마지막 업데이트` 시각과 `실시간 동기화` 표시로 데이터 신선도를 확인하십시오.

## 3. IP 관리

![IP 관리](screenshots/ip-management.png)

블랙리스트와 화이트리스트를 조회·검색하는 화면입니다.

- **탭**: `통합 뷰` / `화이트리스트` / `블랙리스트`를 전환합니다.
- **필터**: 구분(전체·블랙·화이트)과 소스(예: REGTECH)로 목록을 좁힙니다.
- **검색**: `IP 주소 검색...`에 주소를 입력해 특정 IP의 등록 여부를 확인합니다.
- **표 항목**: 구분, IP, 사유, 소스, 국가, 상태, 탐지일, 해제일, 탐지횟수, 등록일. 사유에는 탐지된 공격 유형(예: 원격코드 실행 공격 탐지)이 표시됩니다.
- **Raw Data**: 우측 상단 버튼으로 현재 목록의 원시 데이터를 낮받을 수 있습니다.

상태가 `활성`인 IP가 현재 차단 대상이며, `해제일`이 지나면 소스 정책에 따라 해제됩니다.

## 4. 분석

![분석](screenshots/analytics.png)

탐지일 기준의 일별 통계와 추세를 제공합니다. 기간별 수록량 변화와 소스별 분포를 확인하는 용도로 사용합니다.

## 5. 참고 화면

데이터 수집, FortiGate, Cloudflare 연동, 데이터베이스 화면의 설정 변경은 관리자 권한이 필요합니다. 화면별 운영 절차는 관리자 가이드를 참조하십시오.

## 6. 문제가 보이면

- 로그인이 되지 않음: 자격증명 확인 후 관리자에게 재발급 요청
- 통계가 오래됨: 대시보드의 `마지막 업데이트` 확인 후 관리자에게 수집 상태 점검 요청
- 특정 IP가 잘못 차단됨: IP 관리에서 해당 IP를 찾아 관리자에게 화이트리스트 등록 요청
