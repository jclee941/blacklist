# Blacklist 4.1.0 릴리즈 노트

## 릴리즈 구성

- `4.1.0` 태그와 버전 라벨을 적용한 오프라인 Docker 이미지 5종
- 오프라인 설치 프로그램과 운영 Compose 설정
- 이미지 및 패키지 SHA-256 검증 파일
- 한국어 오프라인 배포·운영 가이드

## 패치 내역

### 데이터 수집

- REGTECH 요청의 페이지네이션과 요청 파라미터를 수정했습니다.
- 필수 수집 날짜 형식과 페이지 크기 처리를 추가했습니다.
- 다중 소스 REGTECH 수집 경로의 페이지 크기와 최대 페이지 계산을 수정했습니다.
- 다른 수집 요청에는 영향을 주지 않고 REGTECH 트리거 제한 시간을 늘렸습니다.
- REGTECH 자격증명이 없거나 복호화할 수 없으면 수집을 시작하지 않습니다.

### 자격증명

- Collection 화면에서 REGTECH 자격증명을 설정하고 저장할 수 있습니다.
- 저장된 비밀번호는 API와 화면에 다시 노출되지 않습니다.

### Cloudflare 연동

- Cloudflare 전용 연동 화면과 전역 메뉴를 추가했습니다.
- 기존 암호화 자격정보 저장소와 연결 테스트 API를 재사용했습니다.
- 좁은 화면에서 설정 폼 배치를 개선했습니다.

### 배포 및 운영

- 저장소 루트 실행 기준으로 Compose 파일 경로를 수정했습니다.
- 운영에 필요한 내용만 담은 오프라인 배포 PDF를 추가했습니다.
- 일반 `install.sh` 실행 시 모든 실행 중인 Docker 컨테이너를 중지한 후
  Blacklist 서비스를 교체·기동하도록 변경했습니다.
- Docker 조회, 컨테이너 중지, Compose 기동 또는 필수 헬스 체크가 실패하면
  설치가 성공으로 보고되지 않도록 변경했습니다.
- App과 Collector 이미지가 Python 3.11에서 빌드되도록 NumPy 의존성 범위를 수정했습니다.
- 모든 릴리즈 이미지에서 개인 maintainer 메타데이터를 제거했습니다.
- 설치 전에 데이터베이스 비밀번호와 자격증명 암호화 키를 필수로 검증합니다.
- Collector를 내부 브리지 네트워크에 연결하고 host port를 공개하지 않았습니다. Collector에는 JWT 검증이 없으므로 JWT 강제 적용은 ADR-0002에 따라 보류합니다.

## 설치 시 중요 사항

`install.sh`을 실행하면 서버에서 실행 중인 모든 Docker 컨테이너가 중지됩니다.
설치 후에는 Blacklist 서비스만 기동됩니다. 그 외 필요한 컨테이너는 운영 절차에 따라
별도로 기동해야 합니다.

## 검증 결과

- 이미지 5종의 버전 라벨이 모두 `4.1.0`임을 확인했습니다.
- 아카이브 체크섬, 패키지 매니페스트, 이미지 5종 체크섬 검증을 통과했습니다.
- Compose 설정 검증을 통과했습니다.
- 설치 프로그램 구문 검사와 ShellCheck를 통과했습니다.
- 자격증명과 Collector fail-closed 변경 범위의 Python 테스트를 통과했습니다.
- Frontend 단위 테스트 436개와 production build를 통과했습니다.
- Chromium에서 Collection 화면의 자격증명 저장 흐름을 확인했습니다.
- 통제된 Docker 모의 환경에서 전체 설치 흐름을 실행해 모든 실행 중인 컨테이너를
  중지한 후 `docker compose up -d`를 호출하는 순서를 확인했습니다.
- A4 9페이지 운영 가이드의 텍스트 추출과 페이지별 렌더링 검사를 통과했습니다.
