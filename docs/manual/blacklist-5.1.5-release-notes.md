# Blacklist 5.1.5 릴리스 노트

## 요약

Blacklist 5.1.5는 제로베이스 오프라인 설치 및 REGTECH 데이터 수집 과정에서 발견된 주요 버그들을 수정하고, 대시보드 상태 표시에 존재하던 오류를 해결한 패치입니다.

## 수정 사항

- **배포/설치:** `install.sh`에서 collector 볼륨의 소유권을 변경할 때 `CAP_FOWNER` 누락으로 인해 100% 발생하던 `EPERM` 오류를 수정하여, 제로베이스 설치가 정상적으로 완료되도록 개선했습니다.
- **데이터 수집:**
  - `MAX_PAGES_PER_COLLECTION` 변수가 컨테이너로 전달되지 않던 문제를 수정하여, 90일치 데이터 수집 시 1,000건에서 잘리던 한계를 해소했습니다 (기본값 20페이지 유지, 오버라이드 가능).
  - REGTECH 수집 시 WAF/세션 만료(HTTP 302/401/500)가 발생하면 즉시 인증 캐시를 무효화하여 죽은 세션을 재사용하는 문제를 해결했습니다.
- **프론트엔드 대시보드:** `/api/dashboard/status` 응답의 envelope 구조(`{success, data}`)를 올바르게 파싱하도록 수정하여, 실제로는 정상 상태인 API 서버와 데이터베이스가 대시보드에 항상 "오류"로 표시되던 버그를 고쳤습니다.

## 알려진 문제

- `RATE_LIMIT_WHITELIST` 변수가 `.env.example`에는 문서화되어 있으나 `deploy/base.yml`에서 실제 앱 컨테이너로 전달되지 않고 있습니다. E2E 테스트와 같은 단일 IP 대량 접근 시 로그인 속도 제한(5/min)에 걸릴 수 있습니다.
