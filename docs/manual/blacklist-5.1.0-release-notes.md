# Blacklist 5.1.0 릴리즈 노트

REGTECH 수동 수집이 50페이지에서 종료되어 최근 90일 데이터 일부만 저장하던 문제를 수정했습니다.

## 수정 내용

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 수동·강제 수집 범위 | 최근 3개월 | 최근 90일 |
| 페이지 제한 | 최대 50페이지 | 빈 페이지가 반환될 때까지 수집 |
| 일일 자동 수집 | 최근 1일, 1페이지 | 변경 없음 |

REGTECH 포털의 실제 페이지 크기는 50건입니다. 기존 제한은 원본 2,500건에서 수집을 중단했고, 중복 제거 후 2,337건만 저장했습니다. 수정 후 동일 계정으로 254페이지를 조회해 원본 12,604건, 중복 제거 후 12,107건을 저장했습니다.

## 확인 결과

- 수집 기간: 2026-04-30 ~ 2026-07-29
- 마지막 데이터 페이지: 253페이지, 4건
- 종료 확인: 254페이지에서 데이터 없음
- 최종 REGTECH IP: 12,107건
- 신규 IP: 9,770건
- 기존 IP 갱신: 2,337건
- Collector 단위 테스트: 328개 통과
- 린트: 통과

## 업그레이드

설정 파일이나 데이터베이스 스키마 변경은 없습니다. 기존 5.0.0 설치에 5.1.0 이미지를 적용하면 다음 수동 또는 강제 REGTECH 수집부터 최근 90일 전체 페이지를 조회합니다.
